# 원하는 자료 추가

첫 학습 자료: [AX 개발의 필수 기본 지식](2026-10-30-ax-foundations.md). 공식 문서·명세·원 논문 기반의 연구 노트이며 아직 위키화하지 않은 입력 자료입니다.

공개 가능한 자료를 이 폴더에 넣으세요. Markdown·텍스트·읽을 수 있는 첨부 파일을 사용할 수 있습니다. 링크만 넣은 Markdown도 가능합니다. 고유 파일명으로 새 파일을 추가하면 됩니다.

링크 추가 예시:

```sh
python3 scripts/wiki.py add-url 'https://example.com/article'
```

웹페이지를 다운로드하지 않고 링크 파일만 만듭니다. 같은 URL은 중복 파일을 만들지 않습니다. 직접 GitHub의 Add file → Create new file로 raw/user/이름.md를 만들어도 됩니다. 자료를 추가한 뒤 저장소에서 `$wiki-ingest`를 수동 실행하세요.

공개 저장소이므로 회사 코드, 사용자·고객 정보, 개인 노트, 인증 키는 넣지 마세요.
