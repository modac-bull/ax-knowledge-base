# 수동 위키 구현 계획

최종 요구: 자동화는 raw 자료를 매일 축적하고, 위키는 저장소에서 사람이 스킬을 호출할 때만 갱신한다. 사용자는 raw/user에 자료를 추가할 수 있다. 앞선 자동 인사이트 설계를 대체한다.

1. raw/daily에 기존 형식 리포트, raw/links에 당시 후보 URL을 게시하도록 기존 스크립트를 변경한다. 기존 01-Daily 노트는 보존하고 초기 자료를 raw/daily에 복사한다.
2. 자료 추가·미처리 탐색·처리 완료·링크 검증을 제공하는 scripts/wiki.py를 테스트 우선으로 작성한다. 자료 내용 해시로 중복을 방지하고 변경 자료를 재처리한다.
3. 명시 호출 전용 .agents/skills/wiki-ingest를 작성한다. raw를 비신뢰 입력으로 취급하고 근거가 붙은 wiki만 갱신한다. Gemini나 다른 API를 자동으로 호출하지 않는다.
4. 공식 Codex SessionStart 훅으로 미처리 개수만 알린다. 선택 설치하는 Git pre-commit 훅과 CI에서 검증한다. 훅은 위키 생성·커밋·푸시를 수행하지 않는다.
5. 한국어 사용 안내와 AGENTS.md를 추가한다. 전체 테스트 및 스킬 시나리오 검증 후 승인된 원격 저장소에 게시하고 CI를 확인한다.

무료 일일 Gemini 리포트는 유지한다. 수동 위키는 사용자가 실행한 에이전트의 이용 조건을 따르며 별도 API 키를 요구하지 않는다. 자료 열람 후 위키를 갱신하는 스킬의 준비와 검증까지가 이번 작업이며, 실제 위키 생성은 사용자의 별도 호출로 남긴다.
